# Random Code Playground

This folder contains a **collection of small, random programs and scripts** in many different languages.

You can use them to:

- Try out new languages
- Test your editors / terminals
- Practice running and modifying code

Some examples:

- `random_code_1.js` — Node.js script that prints random numbers.
- `random_code_2.py` — Python script that prints random tokens.
- `random_code_3.html` — Random color grid in the browser.
- `random_code_4.go` — Go program with random hex and sayings.
- `random_code_23.ps1` — PowerShell random code generator.

Feel free to:

- Delete any files you don’t need
- Edit the programs and break them on purpose
- Copy snippets into your own projects

Have fun experimenting. 🙂
